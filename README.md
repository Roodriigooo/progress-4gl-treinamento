# Progress 4GL / OpenEdge ABL - Treinamento

Repositório criado para armazenar meus exercícios, testes e estudos práticos utilizando Progress 4GL / OpenEdge ABL.

O objetivo deste repositório é registrar minha evolução prática com a linguagem, principalmente em consultas, manipulação de dados, procedures, validações e lógica aplicada em ambiente Progress.

## Tecnologias

- Progress 4GL
- OpenEdge ABL
- TOTVS Datasul
- Banco de dados Progress

## Conteúdos deste repositório

Atualmente o repositório possui exemplos relacionados a:

- Consulta de clientes
- Consulta de emitentes
- Consulta de itens
- Alteração de registros
- Exclusão de registros
- Procedures
- Validação de registros
- Uso de `FIND FIRST`
- Uso de `FOR EACH`
- Uso de `AVAILABLE`
- Relacionamento entre tabelas
- Manipulação de dados
