# Progress 4GL / OpenEdge ABL - Treinamento

Repositório destinado aos meus estudos e práticas com **Progress 4GL / OpenEdge ABL**, com foco em consultas, manipulação de dados, procedures, validações e lógica aplicada em ambiente Progress.

O objetivo é centralizar exercícios, exemplos e códigos desenvolvidos durante meu treinamento com a linguagem, mantendo o conteúdo organizado por categoria.

## Tecnologias

- Progress 4GL
- OpenEdge ABL
- TOTVS Datasul
- Banco de dados Progress
